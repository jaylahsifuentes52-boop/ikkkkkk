# Junior AI

A colorful AI workspace inspired by modern chat UIs.

## Features

- Dark theme with purple / pink / cyan accents
- Sidebar with new conversation + recent chats
- Welcome screen with quick actions
- **Home** button that “adds himself” (floating chip appears)
- Simulated chat replies
- **Fix Code** tool — paste code → get cleaned version + “Fix coding” message

## Deploy on Netlify + GitHub

1. Push this folder to a GitHub repository.
2. Go to [Netlify](https://www.netlify.com) → **Add new site** → **Import an existing project**.
3. Connect the GitHub repo and deploy (build command can be left empty; publish directory = root or `/`).

Or simply drag-and-drop the folder onto Netlify’s deploy drop zone for a quick live URL.

## Local preview

Open `index.html` in any modern browser. No build step required.
